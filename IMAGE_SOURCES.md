# Product images

The images under `public/products/` are **placeholders generated for this repository**,
not product photography. Each one carries the product's initials and name so the
comparison UI stays readable, and nothing else.

Earlier revisions of this project used photographs downloaded from each brand's official
product page. Using them inside the running app to identify a specific product is one
thing; redistributing them in a public source repository is another, so they were removed
from the working tree and from the git history.

If you run this yourself and want real imagery, supply your own — either photographs you
took, or images you have a licence to redistribute — using the same filenames.

Product names and brand names appear as text throughout the catalogue. That is nominative
use: naming a product to say which product a price refers to.
