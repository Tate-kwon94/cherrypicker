대상 독자: 제품 책임자, 개발자, 데이터 운영자, 보안·법무 검토자

> 이 문서는 감사 지적을 항목별로 수용·재분류하고 개선 순서와 완료 기준을 정한 관리 답변서다. 아직 수정되지 않은 항목을 완료된 것으로 표시하지 않는다. 법률 관련 판단은 출시 위험 분류이며 변호사의 최종 법률의견을 대체하지 않는다.

## 기술 요약

- 감사의 핵심 방향은 타당하다. 특히 OCR 오인식, 상품 마스터 덮어쓰기, 클라이언트 환경변수 불일치, 타입체크 실패, 가격 표시 신뢰성은 실제 코드와 실행 결과로 확인됐다.
- 원문 활성 64건은 그대로 독립 결함 64건으로 집계하기 어렵다. 본 답변에서는 **수용 37건, 통합 수용 13건, 부분 수용 11건, 추가 검증 2건, 활성 결함으로는 기각 1건**으로 분류한다.
- 원문 마지막의 추가 발견 9건은 별도 범위로 수용한다. 그중 실제 결제가 불가능한 환산가를 원화 절감액으로 표시·저장하는 문제와 OCR의 `최종` 정규식 문제는 출시 전 수정 대상이다.
- 현재 릴리스 판단은 **조건부 중단**이다. 사용자에게 공개적으로 절감액을 추천하거나 광고·제휴 수익화를 켜기 전에 P0 항목을 해결하고 회귀 테스트를 통과해야 한다.
- 특허·수익성 판단은 이 감사의 범위가 아니다. 기술 안정화 이후 별도의 선행기술 조사와 트래픽·광고·제휴 전환 가정이 필요하다.

## 답변 분류와 우선순위 정의

### 답변 분류

| 분류 | 의미 |
|---|---|
| 수용 | 사실·영향이 충분히 입증되어 독립 개선 항목으로 유지 |
| 통합 수용 | 사실은 맞지만 동일 근본 원인의 상위 개선 과제에 병합 |
| 부분 수용 | 코드상 사실은 있으나 영향, 법률 결론 또는 원문 심각도를 조정 |
| 추가 검증 | 플랫폼·운영환경의 외부 사실이 확인되어야 최종 판정 가능 |
| 기각·재분류 | 원문이 주장한 활성 피해가 성립하지 않으며 잠재 위험 또는 문서 과제로만 유지 |

### 개선 우선순위

| 우선순위 | 기준 |
|---|---|
| P0 | 공개 추천·수익화·운영 배포 전에 반드시 해결하거나 명시적으로 기능 비활성화 |
| P1 | 첫 안정화 스프린트에서 해결; 금액 정확성·보안·운영 신뢰에 직접 영향 |
| P2 | 후속 품질 스프린트에서 해결; 접근성·유지보수성·장기 운영 위험 |
| Gate | 외부 플랫폼 또는 법무 확인 전에는 해당 기능을 활성화하지 않음 |

`npm audit`의 최신 취약점 수치는 현재 검증 환경에서 npm 레지스트리로 의존성 그래프를 전송할 권한이 없어 독립 재실행하지 않았다. 의존성 조치는 별도 승인된 환경에서 advisory와 실제 도달 가능성을 다시 확인한다.

## 출시 결정과 선행조건

현재 버전은 빌드와 기존 테스트가 통과하지만, 잘못된 금액을 높은 신뢰도로 추천할 수 있고 미승인 draft가 공개 상품 메타데이터를 바꿀 수 있다. 따라서 다음 조건이 충족될 때까지 공개 절감액 추천 및 광고·제휴 활성화를 보류한다.

1. OCR이 모호한 입력에서 자동확정하지 않고 사용자의 명시적 확인을 요구한다.
2. 상품 마스터 변경과 가격 관측 등록을 분리하고, draft 생성으로 기존 상품이 변경되지 않는다.
3. 환산 단위가와 실제 결제액·절감률을 분리하여 구매할 수 없는 금액을 `절약액`으로 저장하지 않는다.
4. 타입체크·테스트·빌드가 하나의 필수 CI 게이트로 통과한다.
5. Admin 헤더 신뢰 경계와 D1 초기 배포 경로를 실제 운영환경에서 검증한다.
6. 개인정보처리방침, 광고 동의, 이미지 권리, 주류 정보의 광고 해당 여부를 출시 구성에 맞춰 검토한다.

## 제한사항과 미해결 질문

1. OpenAI Sites가 외부 `oai-authenticated-*` 헤더를 제거하는지 공식 증거가 없다.
2. Sites 제어면이 D1 migration을 어떤 조건에서 자동 적용하는지 cold-start 증거가 없다.
3. Cloudflare·OpenAI Sites·Google·Kakao의 실제 계약상 개인정보 처리 역할과 이전 지역을 코드만으로 확정할 수 없다.
4. 위스키 가격 비교·가이드·제휴 링크가 국민건강증진법상 주류 광고에 해당하는지 법률의견이 필요하다.
5. 브랜드 이미지의 사용권 존재 여부는 저장소만으로 확인할 수 없다.
6. 현재 트래픽, AdSense CPC, 제휴 CTR·전환율 데이터가 없어 수익 예상치는 이 문서에서 산출하지 않는다.
7. 핵심 방법은 규칙 기반 가격 정규화와 OCR 후처리로 보이며, 특허 가치는 별도 선행기술 조사 전에는 판단하지 않는다.

## 최종 수용 기준

다음 조건을 모두 만족하면 본 감사의 1차 개선 라운드를 종료한다.

- P0와 Gate 항목이 완료되거나 해당 기능이 배포 구성에서 비활성화되어 있다.
- 타입체크·lint·테스트·build가 clean checkout의 CI에서 통과한다.
- 감사에서 제시된 금액 오인식 사례가 정확히 처리되거나 사용자 확인 단계로 실패-폐쇄된다.
- 미승인 draft와 사용자 직접 입력이 운영자 검수 데이터로 오인되지 않는다.
- 실제 결제액, 단위가, 환산 가치, 절감액의 의미가 UI·저장 데이터·문서에서 일치한다.
- 법무·개인정보·이미지 권리 문구가 실제 활성 기능과 일치하며 확인 기록이 보관된다.
- 원문 항목별 티켓에 코드 변경, 테스트, 검증 증거 또는 기각 근거가 연결되어 있다.
