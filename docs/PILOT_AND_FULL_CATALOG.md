# 파일럿과 전수 상품 확장 계획

## 파일럿의 목적

파일럿은 상품 수를 많이 보유하는 단계가 아니라 가격 비교 결론의 정확도와
운영 비용을 확인하는 단계다.

- 운영 시드 15개(화장품 10개, 주류 5개)로 입력·검수 흐름을 먼저 확인
- 공개 파일럿 카탈로그 100개(화장품 70개, 주류 30개)
- 100개 중 30개는 면세·국내 핵심 판매처를 모두 검수한 `골드 상품`
- 롯데·신라·신세계·현대 온라인 면세점 4곳을 모두 조회
- 상품당 서로 다른 온라인 면세 2곳과 국내 리테일·픽업 2곳 이상
- 최소 60개의 유효한 가격 관측값
- 별도 상황 질문 없이 면세와 국내 대안을 동시에 보여주는 결론 검증
- 가격 하나를 확인·등록·승인·갱신하는 데 드는 시간 측정

가격이 없는 파일럿 상품은 소비자 추천에 노출하지 않는다. 운영자 화면의
커버리지 표에서 면세 2곳과 국내 2곳이 모두 확보된 상품만 완료로 계산한다.
취급하지 않음·품절도 조회 결과로 기록하되 유효 가격 수에는 포함하지 않는다.

## 전수의 현실적인 정의

모든 쇼핑몰의 모든 상품을 수동으로 등록하는 전수 방식은 유지할 수 없다.
로그인 회원가, 쿠폰, 품절, 세트 구성과 지역별 픽업 재고가 계속 달라지기
때문이다.

체리피커의 전수 범위는 다음처럼 정의한다.

1. 사용자가 많이 찾는 핵심 상품의 80%를 우선 커버한다.
2. 나머지는 검색 요청이 들어올 때 수집 대기열에 넣는다.
3. 공식 API·제휴 피드가 있는 판매처는 자동 갱신한다.
4. 자동 수집이 허용되지 않거나 로그인 가격인 판매처는 운영자 검수 또는
   사용자 결제 화면 입력으로 보완한다.

## 전수 확장 데이터 흐름

### 1. 표준 상품 카탈로그

- 브랜드, 표준 상품명, 카테고리
- 용량·수량과 세트 구성
- 판매처별 상품명 별칭
- 판매처 상품 코드, 바코드와 원본 URL
- 주류의 숙성 연수·제품군, 선택적 도수·배치 정보

하나의 표준 상품에 여러 판매처 상품을 연결한다. 화장품은 구성품 전체 용량,
주류는 같은 병 비교와 100ml 가성비 비교를 분리한다.

### 2. 판매처 연결

우선순위는 공식 제휴 API·상품 피드, 판매처가 허용한 데이터 제공 방식,
운영자 확인 순서다. 수집 원본은 바로 공개하지 않고 관측 데이터로 저장한다.

### 3. 정규화

- 상품가 + 필수 배송비·수령비
- 누구나 받을 수 있는 즉시할인
- 실제 비교 용량·수량
- 화장품 1ml·1g·1개, 주류 100ml 단가
- 회원가·카드가·개인 쿠폰은 조건부 가격으로 분리

### 4. 상품 매칭

판매처 상품을 표준 상품에 연결하고 신뢰도를 기록한다.

- 높은 신뢰도: 상품 코드 또는 핵심 상품명·구성 일치
- 중간 신뢰도: 브랜드·제품군·용량 일치, 운영자 확인 필요
- 낮은 신뢰도: 자동 추천에서 제외하고 검수 대기

도수와 바코드는 일반 주류에서 보조값이며, 캐스크 스트렝스·싱글 캐스크처럼
배치가 상품을 바꾸는 경우에만 분리 조건으로 사용한다.

### 5. 검수·갱신 대기열

- 신규 상품 매칭
- 가격 급등락
- 구성 변경
- 품절·재입고
- 유효기간 만료
- 사용자 오류 신고

변화가 없으면 자동 승인하고, 이상값만 운영자가 확인하는 방식으로 수동 작업을
줄인다.

## 단계별 목표

### 단계 0 · 운영 시드 15개

- 4대 온라인 면세점을 모두 조회하고 최소 60개 가격 관측값 확보
- 상품별 면세 2곳·국내 2곳의 최저 단위가 비교
- 전부 수동 검수
- 잘못된 추천 사례와 갱신 시간 측정

### 단계 1 · 공개 파일럿 100개

- 화장품 70개, 주류 30개
- 완전 검수 골드 상품 30개, 나머지는 가능한 경우 채널별 2개 출처 확보
- 화장품: 스킨케어 40, 메이크업 15, 향수 15
- 주류: 위스키 20, 기타 주류 10
- 캡처에서 인식되지 않은 검색 상품을 확장 후보 대기열에 추가

### 단계 2 · 핵심 300개

- 화장품 200개, 주류 100개
- 판매처별 상품 별칭과 자동 단가 계산
- 공식 피드·제휴 데이터와 운영자 수집 혼합

### 단계 3 · 핵심 3,000개

- 검색 수요에 따라 자동 우선순위
- 변경된 가격만 재검수
- 일본·중국 판매처는 통화·세금·수령 국가를 별도 조건으로 추가

### 단계 4 · 롱테일

- 사용자가 검색한 미등록 상품을 수집 요청으로 저장
- 검색량과 제휴 가능성을 기준으로 등록 순서 결정
- 실제 수요가 없는 상품은 상시 수집하지 않음

## 전수 운영에 필요한 외부 준비

- 판매처별 제휴 계정·API 또는 상품 피드 사용 권한
- 쿠팡 파트너스 추적 정보
- 가격 수집·표시가 가능한 이용약관 검토
- 통화 환율, 관부가세와 면세 한도 기준
- 운영자 검수 인력과 일일 갱신 가능량
- 상품 이미지 사용 권한

전수 확장의 핵심 지표는 등록 상품 수가 아니라 `검색 수요 대비 유효 가격
커버리지`, `양쪽 채널 가격 보유율`, `가격 갱신 지연`, `추천 오류율`이다.
