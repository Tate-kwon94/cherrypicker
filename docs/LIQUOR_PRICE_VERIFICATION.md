# 주류 가격 비교·검증 기준

체리피커는 주류를 직접 판매하거나 배송하지 않는다. 온라인면세점의 출국장
수령 가격과 국내의 합법적인 성인 인증 매장 픽업 가격을 환산해 보여주고,
사용자가 판매처에서 최종 조건을 확인하도록 연결한다.

## 두 가지 비교 모드

### 1. 같은 병 가격 비교

동일한 상품의 면세점·국내 픽업 가격을 비교할 때는 아래 핵심 정보가
일치해야 한다.

- 브랜드와 핵심 상품명
- 숙성 연수 또는 제품 등급
- 병 용량(ml)
- 단품·세트·기프트 패키지 구성

알코올 도수, 배치, 판매 국가와 바코드는 필수 일치 조건으로 사용하지 않는다.
해당 정보는 배치나 국가별 유통 사양에 따라 달라질 수 있으므로 확인된 경우에만
`높은 일치 신뢰도`를 부여하는 참고값으로 사용한다. 단, 싱글 캐스크·캐스크
스트렝스·한정판처럼 배치 차이가 상품 성격을 바꾸는 경우에는 별도 상품으로
분리한다.

### 2. 가성비 탐색

서로 다른 병 또는 다른 용량을 탐색할 때는 다음 값을 기본 지표로 사용한다.

`100ml당 실결제가 = (상품가 + 필수 비용 - 누구나 받는 즉시할인) ÷ 용량 × 100`

이는 같은 상품이라는 뜻이 아니라 가격 대비 용량을 빠르게 보는 지표다.
위스키의 숙성 연수, 주종, 맛과 희소성은 별도 필터로 유지한다. 순수 알코올
환산 가격은 도수가 중요한 일부 주종에서만 보조 지표로 제공하고, 전체 주류의
기본 순위에는 사용하지 않는다.

## 가격 증거와 갱신 주기

### 공식 상품 페이지

- 면세점 또는 판매처가 직접 게시한 상품 URL
- 로그인 후 확인되는 상품가, 즉시할인과 최종 결제가
- 출국 공항, 주문 마감, 수령 조건
- 확인 시각으로부터 24시간 동안 체리픽 계산에 사용
- 이후 최근 30일 안에서는 참고가격으로만 표시

### 성인 인증 스마트오더·매장 픽업

- 주류 판매 자격을 갖춘 판매처의 주문·결제 및 픽업 페이지
- 수령 매장, 재고 여부, 성인 인증 조건
- 택배 가격으로 오해될 수 있는 표현을 사용하지 않음
- 확인 시각으로부터 최대 7일

국내 픽업 가격원은 전문 주류몰뿐 아니라 편의점 스마트오더를 포함한다.

- 포켓CU 예약구매
- GS25 와인25플러스
- 세븐일레븐 앱 주류 픽업
- 이마트24 보틀오더

편의점 가격은 체인 공통가로 가정하지 않는다. 같은 상품이라도 선택 지점,
재고, 앱 쿠폰과 행사 기간에 따라 달라질 수 있으므로 판매처 이름과 함께
수령 지점 또는 `주문 시 수령점 선택` 조건, 재고 상태, 확인 시각을 기록한다.
공개 화면에서는 이를 `편의점 픽업`으로 별도 표시한다.

국세청은 모바일로 주문·결제하고 고객이 매장에서 직접 수령하는 주류
스마트오더를 허용한다고 안내한다.

https://www.nts.go.kr/webtv/na/ntt/selectNttInfo.do?nttSn=851264

### 영수증·매장 가격표

- 매장명과 지점, 구매·확인 시각이 식별되어야 함
- 핵심 상품명과 병 용량이 확인되어야 함
- 도수·바코드는 보이면 기록하되 필수로 요구하지 않음
- 회원 전용·카드 전용·묶음 할인은 조건부 가격으로 표시
- 운영자 검수 후 최대 3일

## 승인 제외

- 지점과 확인 시각이 없는 커뮤니티 글
- 상품 구성이나 용량이 보이지 않는 가격표
- 개인간 거래, 병행판매 진위가 불명확한 링크
- 품절 가격(사용자가 `품절 포함`을 선택한 경우에만 참고로 표시)
- 최신성 기준을 지난 가격은 추천에서 제외하고 참고가격으로만 표시
- 일반 주류의 택배 배송을 전제로 한 판매 링크
- 특정 개인만 받을 수 있는 쿠폰을 일반 최저가로 표시한 값

## 사용자 표시

공개 가격에는 판매처, 확인 시각, 병 용량, 100ml당 실결제가, 픽업 지점과
수령·재고 조건을 함께 표시한다. 같은 병 비교인지 가성비 탐색인지 명확히
구분하고, 도수·바코드는 확인된 경우에만 참고 정보로 보여준다.
