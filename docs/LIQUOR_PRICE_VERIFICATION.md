# 주류 가격 검증 기준

체리피커는 주류를 직접 판매하거나 배송하지 않는다. 온라인면세점의 출국장
수령 가격과 국내의 합법적인 성인 인증 매장 픽업 가격을 같은 병 기준으로
비교하고, 사용자가 판매처에서 최종 조건을 확인하도록 연결한다.

## 상품 일치 조건

아래 정보가 일치하지 않으면 같은 상품으로 비교하지 않는다.

- 브랜드와 정확한 상품명
- 병 용량(ml)과 알코올 도수(ABV)
- 숙성 연수, 배치, 캐스크, 에디션
- 단품·잔 포함 세트·기프트 패키지 구성
- 바코드, SKU 또는 판매처 상품 코드

## 가격 증거 등급

### 1. 공식 상품 페이지

- 면세점 또는 판매처가 직접 게시한 상품 URL
- 로그인 후 확인되는 상품가, 즉시할인과 최종 결제가
- 출국 공항, 주문 마감, 수령 조건
- 확인 시각으로부터 최대 7일

### 2. 성인 인증 스마트오더·매장 픽업

- 주류 판매 자격을 갖춘 판매처의 주문·결제 및 픽업 페이지
- 수령 매장, 재고 여부, 성인 인증 조건
- 택배 가격으로 오해될 수 있는 표현을 사용하지 않음
- 확인 시각으로부터 최대 3일

국세청은 모바일로 주문·결제하고 고객이 매장에서 직접 수령하는 주류
스마트오더를 허용한다고 안내한다.

https://www.nts.go.kr/webtv/na/ntt/selectNttInfo.do?nttSn=851264

### 3. 영수증·매장 가격표

- 매장명과 지점, 구매·확인 시각이 식별되어야 함
- 상품명, 병 용량, 도수 또는 바코드가 확인되어야 함
- 회원 전용·카드 전용·묶음 할인은 조건부 가격으로 표시
- 운영자 검수 후 최대 2일만 공개

## 승인 제외

- 지점과 확인 시각이 없는 커뮤니티 글
- 상품 구성이 보이지 않는 가격표
- 개인간 거래, 병행판매 진위가 불명확한 링크
- 품절 또는 유효기간이 지난 가격
- 일반 주류의 택배 배송을 전제로 한 판매 링크
- 특정 개인만 받을 수 있는 쿠폰을 일반 최저가로 표시한 값

## 사용자 표시

공개 가격에는 판매처, 증거 등급, 확인 시각, 만료 시각, 병 정보, 픽업 지점과
수령 조건을 함께 표시한다. 증거가 부족하면 추천 계산에서 제외하고
`참고 가격`으로만 보여준다.
